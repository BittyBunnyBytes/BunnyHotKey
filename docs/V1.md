# AutoHotkey v1 compatibility

BHK accepts common v1 keyboard/mouse scripts through a source frontend feeding
its existing native runtime. Original `.ahk` files do not need to be converted.

```
bhk --console script.ahk
bhk --console --validate script.ahk
bhk --ahk-version=1 script.ahk
bhk --ahk-version=2 script.ahk
```

The default `auto` mode respects `#Requires AutoHotkey v1`/`v2`, then looks for
v1 directives, comma commands, and unbraced hotkey bodies. Ambiguous scripts
remain v2. Explicit version selection conflicting with `#Requires` fails.
Included files participate in the same script-wide detection.

Supported legacy forms:

- Unbraced hotkey bodies ending in `return`, stacked hotkeys, inline commands,
  and key remaps. Auto-execution stops at the first hotkey.
- Shared global variables in hotkey bodies; reads of unset variables produce
  an empty string in v1 mode. Expression assignments and loops use BHK's parser.
- `#If`, `#IfWinActive`, `#IfWinNotActive`, `#IfWinExist`, `#IfWinNotExist`,
  including empty directives that reset the condition.
- Literal assignment (`name = Bunny`), `%name%` substitution and forced
  expression arguments (`% expression`).
- Send/SendInput/SendEvent/SendPlay/SendRaw, SendMode, Sleep, KeyWait,
  SetWorkingDir, CoordMode, MouseGetPos output variables, MouseMove,
  MouseClick, Click, keyboard/mouse/window/control delay settings,
  SetTitleMatchMode, WinActivate/WinWait/WinWaitActive/WinClose,
  FileAppend, ToolTip, ExitApp, Reload, Pause and Suspend.

This is a bounded compatibility layer, not a complete v1 interpreter. Legacy
GUI/MsgBox command signatures, Gosub/label subroutines, v1 object semantics,
traditional `If var = value`, ErrorLevel conventions and all historical v1
version-specific behaviors are not implemented. Unsupported comma commands
produce a source-located load error. Existing v2 runtime/backend limitations
still apply. `--validate` checks loading and compilation, not live desktop
behavior or every runtime error.

`python3 tests/test_v1.py` checks copies of the six home/Downloads scripts,
including their startup, toggle state, finite loop execution, mouse output
variables and window-condition registration on the null backend. It does not
establish in-game behavior. `python3 tests/run.py` includes this suite alongside
the v2 regression tests.

Syntax reference: [official v1 language documentation](https://github.com/AutoHotkey/AutoHotkeyDocs/blob/v1/docs/Language.htm).
